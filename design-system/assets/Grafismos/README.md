# Grafismos

`faixas-douradas.svg`: as duas faixas diagonais paralelas com pontas arredondadas, em `dourado-escuro` (#9A7D44), extraídas do PPT. Ficam no canto inferior direito, sangrando pela borda de baixo (classe `cah-faixas`). Use no máximo um par por slide, sempre nessa posição e nesse ângulo. A cor é fixa no arquivo.
