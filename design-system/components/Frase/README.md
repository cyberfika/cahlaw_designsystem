# Frase

Slide de impacto: uma única frase em CAIXA ALTA, negrito itálico, centralizada sobre a águia, com o símbolo no canto superior esquerdo e as faixas douradas no inferior direito (slide 4 do PPT).

**Você fornece:** uma frase de no máximo duas linhas (até ~8 palavras), sem ponto final.

```html
<section class="cah-slide cah-frase" data-theme="escuro">
  <img class="cah-aguia" src="aguia-fundo-conteudo.png" alt="">
  <img class="cah-icone" src="cah-icone.svg" alt="">
  <h2 class="cah-frase__texto cah-titulo titulo-frase">Visão de longo alcance, execução precisa</h2>
  <img class="cah-faixas" src="faixas-douradas.svg" alt="">
</section>
```

- O CSS aplica a caixa alta; escreva a frase normalmente.
- Use para abrir uma seção ou fechar um argumento. Nunca dois slides Frase seguidos.
